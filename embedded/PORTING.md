# Contiki-NG / nRF52840 porting boundary

The Python project is the executable oracle for a future embedded port. Keep
the serialized formats and test vectors stable while replacing these modules:

1. Replace `ResearchSampler` with a constant-time discrete-Gaussian sampler
   driven by the platform CSPRNG.
2. Replace NumPy convolution with fixed-workspace negacyclic multiplication.
   For `q = 2^32`, unsigned 32-bit wraparound implements coefficient reduction.
3. Expand one seeded row of `A` at a time. Do not retain the full matrix.
4. Replace `Db2Codec` with the certified fixed-point lifting implementation.
5. Store one 4,096-byte aggregate accumulator and one block buffer. Reject and
   clear the complete batch after any invalid, duplicate, or missing block.
6. Bind each block tag to the signed ticket digest, node identity, block index,
   total block count, and payload exactly as specified in `transport.py`.
7. Replace the development Ed25519 adapter with the selected post-quantum
   ticket mechanism.
8. Obtain total RAM from the linker map and a runtime high-water mark. The
   Python `stack_ram_bytes` field is not a hardware measurement.

The embedded test harness should import ciphertext, aggregate, and tampering
vectors generated by the host code and reproduce every test in `tests/`.
