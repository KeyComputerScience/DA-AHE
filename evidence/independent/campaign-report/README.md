the complete raw bundle. The full `simulation/` directory, source snapshots,
exogenous inputs and packet/epoch logs are in `DA-AHE-independent-evidence.tar`.

The archive must be uploaded to durable public storage before treating this
repository alone as a complete supplementary evidence release.
