## Supported advantages and the evidence needed to demonstrate them

1. **Payload structure:** one protected packed plaintext versus two raw plaintexts gives an inspectable 8,192→4,096-byte encrypted payload reduction at the specified tuple. It does not establish halved end-to-end latency, radio energy, or network loss by itself.
2. **Trust separation:** block HMACs filter external pollution while the signed roster and hidden aggregate tag address the compromised-gateway setting under the paper's trusted-source/sink assumptions. The adversarial tests target this distinction directly.
3. **Safety before optimization:** runtime decisions cannot trade security, no-wrap or resource constraints for a lower objective. Missing calibration/certificate artifacts stay explicit and block certification.
4. **Reviewer-verifiable analysis:** the package keeps source hashes, paired-seed provenance, raw values, ratio estimands, censoring and missing evidence explicit. It does not transform publication means into synthetic validation data.

Numerical superiority, 128.1-bit security calibration, 2^-128 batch correctness, reconstruction PRD, embedded memory bounds and exact OMNeT++ reproduction remain evidence-dependent. The source package is a foundation for completing that evaluation, not a substitute for the missing author artifacts.
